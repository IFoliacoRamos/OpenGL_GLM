# 3D Minecraft Creeper Animation – Bézier Curve

**Computer Graphics Course Project**

---

## 🇬🇧 English

### 1. Project Description

This project was developed as part of the **Computer Graphics** course. It consists of a 3D scene created using OpenGL, featuring a Minecraft Creeper character that moves along a Bézier curve.

The main purpose of the project is to apply fundamental computer graphics concepts, including 3D modeling, rendering, transformations, camera management, shaders, and curve-based animation.

The scene includes a 3D environment with a ground plane, sky, coordinate axes, and a camera that allows the user to observe the character and its movement.

### 2. Project Features

- 3D rendering using OpenGL.
- Importing and displaying a 3D Minecraft Creeper model.
- Bézier curve implementation for character movement.
- Animation of the character along the defined path.
- Camera control and 3D scene navigation.
- Vertex and fragment shaders for rendering.
- 3D transformations using GLM.
- 3D model loading using Assimp.

### 3. Technologies and Libraries

- **C++:** Main programming language.
- **OpenGL:** Graphics rendering API.
- **GLFW:** Window creation and input management.
- **GLAD:** OpenGL function loading.
- **GLM:** Mathematical operations and 3D transformations.
- **Assimp:** 3D model importing and processing.
- **Visual Studio 2019:** Development environment.
- **GLSL:** Shader programming language.

### 4. Project Structure

The project contains the following main components:

- `models/`: Contains the 3D character model and related resources.
- `shaders/`: Contains the vertex and fragment shaders.
- `main.cpp`: Main source code, including scene initialization, rendering, camera management, and animation.
- `Origin`: Component responsible for representing the coordinate axes.

### 5. Requirements

To compile and run the project, the following are required:

- Visual Studio 2019.
- C++ compiler with C++17 support.
- OpenGL-compatible graphics hardware and drivers.
- Required libraries: GLFW, GLAD, GLM, and Assimp.
- All project resources, including the 3D model and shader files.

### 6. How to Run

1. Clone or download this repository.
2. Open the `.sln` solution file in Visual Studio 2019.
3. Make sure the required libraries and dependencies are correctly configured.
4. Verify that the model and shader resource paths are correct.
5. Build the project.
6. Run the application.

### 7. Academic Purpose

This project demonstrates the practical application of concepts studied in Computer Graphics, combining programming, mathematical transformations, 3D visualization, and animation in an interactive graphical environment.

## 🇪🇸 Español

### 1. Descripción del proyecto

Este proyecto fue desarrollado como parte de la asignatura de **Computación Gráfica**. Consiste en una escena tridimensional creada utilizando OpenGL, en la que un personaje Creeper de Minecraft se desplaza siguiendo una curva de Bézier.

El objetivo principal es aplicar conceptos fundamentales de computación gráfica, como modelado y renderizado 3D, transformaciones geométricas, manejo de cámara, shaders y animación mediante curvas.

La escena cuenta con un entorno tridimensional compuesto por un plano de suelo, cielo, ejes de coordenadas y una cámara que permite visualizar al personaje y su movimiento.

### 2. Características principales

- Renderizado de gráficos tridimensionales mediante OpenGL.
- Importación y visualización de un modelo 3D de Minecraft Creeper.
- Implementación de una curva de Bézier para definir la trayectoria del personaje.
- Animación del personaje siguiendo la trayectoria establecida.
- Control de cámara y navegación por la escena 3D.
- Uso de shaders de vértices y fragmentos para el renderizado.
- Aplicación de transformaciones tridimensionales mediante GLM.
- Carga y procesamiento de modelos 3D mediante Assimp.

### 3. Tecnologías y bibliotecas utilizadas

- **C++:** Lenguaje principal de programación.
- **OpenGL:** API utilizada para el renderizado gráfico.
- **GLFW:** Creación de ventanas y gestión de entradas del usuario.
- **GLAD:** Carga de funciones de OpenGL.
- **GLM:** Operaciones matemáticas y transformaciones 3D.
- **Assimp:** Importación y procesamiento de modelos 3D.
- **Visual Studio 2019:** Entorno de desarrollo.
- **GLSL:** Lenguaje utilizado para la programación de shaders.

### 4. Estructura del proyecto

El proyecto está organizado en los siguientes componentes principales:

- `models/`: Contiene el modelo tridimensional del personaje y sus recursos asociados.
- `shaders/`: Contiene los shaders de vértices y fragmentos.
- `main.cpp`: Código principal, donde se realiza la inicialización de la escena, el renderizado, el manejo de la cámara y la animación.
- `Origin`: Componente encargado de representar los ejes de coordenadas.

### 5. Requisitos

Para compilar y ejecutar el proyecto se necesita:

- Visual Studio 2019.
- Compilador de C++ compatible con C++17.
- Hardware y controladores compatibles con OpenGL.
- Bibliotecas necesarias: GLFW, GLAD, GLM y Assimp.
- Todos los recursos del proyecto, incluyendo el modelo 3D y los archivos de shaders.

### 6. Instrucciones de ejecución

1. Clonar o descargar este repositorio.
2. Abrir el archivo de solución `.sln` en Visual Studio 2019.
3. Verificar que las bibliotecas y dependencias estén correctamente configuradas.
4. Comprobar que las rutas de los modelos y shaders sean correctas.
5. Compilar el proyecto.
6. Ejecutar la aplicación.

### 7. Propósito académico

Este proyecto permite demostrar la aplicación práctica de los conceptos estudiados en Computación Gráfica, integrando programación, transformaciones matemáticas, visualización tridimensional y animación en un entorno gráfico.
